# Вслух

Музыкальный плеер для Windows в том же тёмном стиле, что и био-сайт.
Играет музыку с компьютера, показывает синхронный текст песни, рисует эквалайзер
вокруг обложки и умеет читать, что играет в **других** приложениях — Spotify,
Яндекс Музыке, браузере, AIMP, Telegram.

Своей музыки нет? Ищет и качает через yt-dlp — пачками, очередью, хоть целыми плейлистами
по ссылке. Всё скачанное сразу попадает в библиотеку с тегами и обложкой.

---

## Запуск

```bash
npm start
```

Первый запуск попросит указать папку с музыкой. Дальше приложение само прочитает
теги, длительность и обложки. Поддерживает mp3, m4a, flac, ogg, opus, wav, aac, wma.

## Сборка .exe

```bash
npm run build
```

Готовый установщик появится в папке `dist`.

---

## Первый запуск

Тому, у кого ещё ничего нет, плеер сразу задаёт один вопрос — откуда брать музыку:

- **Она есть на компьютере** — выбираешь папку, плеер её читает и открывает библиотеку.
- **Музыки нет** — ставит yt-dlp и открывает поиск, чтобы можно было сразу что-то найти.

Есть и «Разберусь сам» — тогда просто открываются настройки. Спрашивается это один раз.

## Что умеет

**Библиотека.** Указываешь папки — приложение рекурсивно их обходит и строит список.
Повторное сканирование перечитывает только изменившиеся файлы, поэтому работает быстро.
Поиск по названию, артисту и альбому. Правый клик по треку — показать файл в проводнике.
Сортировка по артисту, названию, альбому, длине или дате добавления.

**Избранное и плейлисты.** На строке трека при наведении появляются два значка: сердечко
кидает трек в любимые, второй — в плейлист. Над списком вкладки: **Все**, **♥ Любимые**
и все твои плейлисты. Новый заводится кнопкой **+ плейлист**, переименовывается двойным
кликом по вкладке, удаляется крестиком. Внутри плейлиста сохраняется свой порядок,
сортировка на него не действует.

**Перетаскивание.** Брось файлы прямо в окно — заиграют сразу, ничего сканировать не надо.
Бросишь папку — она добавится в библиотеку насовсем.

## Поиск

Отдельная вкладка. Ищет по каталогам **Deezer** и **iTunes** — без ключей и регистраций,
работает сразу. Показывает название, артиста, альбом, год, длительность и обложку,
даёт послушать **30-секундный отрывок** прямо в плеере и помечает то, что у тебя уже есть.

Рядом с каждым треком кнопки **Яндекс**, **VK**, **YouTube** — открывают его в браузере
в соответствующем сервисе.

**Подобрать теги** (в настройках, рядом с папками) проходит по трекам, у которых не хватает
артиста или альбома, находит их в каталоге и проставляет данные вместе с обложкой.
Сами файлы при этом не меняются — правки живут в библиотеке приложения
(`%APPDATA%\vsluh\library.json`), так что откатить можно, удалив этот файл
и пересканировав папки.

## Скачивание

Скачивание работает через **yt-dlp** — отдельную маленькую программу, которая ставится одной
кнопкой из настроек. Как только она на месте, вкладка «Поиск» в режиме **YouTube** начинает
искать без всяких ключей, а у каждого результата появляется кнопка со стрелкой вниз.

Нажал — трек скачивается к тебе в папку (по умолчанию `D:\Music`, меняется в настройках),
сразу попадает в библиотеку, и ему подбираются артист, альбом и обложка по каталогу.
Дальше это обычный локальный файл: эквалайзер, караоке, темы — всё работает.

Качается только звуковая дорожка, поэтому **ffmpeg не нужен**. Трек на 4 минуты весит
примерно 4 МБ.

Где взять: нажать **Скачать yt-dlp** в *Настройках → Стриминг*. Приложение само возьмёт
свежую версию с [официальных релизов](https://github.com/yt-dlp/yt-dlp/releases/latest),
сверит контрольную сумму с опубликованной там же и положит файл рядом со своими настройками
(`%APPDATA%\vsluh`). На диск файл ложится только после сверки — битый или подменённый
не сохранится. Той же кнопкой потом обновлять: YouTube ломает yt-dlp примерно раз в месяц.

Можно и вручную: положить `yt-dlp.exe` в корень проекта, приложение его найдёт.

### Очередь

Слева от каждого результата — квадратик. Отметил несколько, нажал **Скачать выбранное** —
и всё встало в очередь. Кнопки **Все** и **Снять** над списком выделяют и сбрасывают разом.

Очередь висит отдельной панелькой в правом нижнем углу и видна с любой вкладки: что качается
сейчас и на сколько процентов, что ждёт, что готово, что не вышло и почему. Её можно свернуть
стрелкой, поставить на паузу, убрать доделанное корзиной, а любой трек вычеркнуть крестиком —
текущий при этом обрывается сразу.

Качается строго по одному: параллельные загрузки YouTube не любит. Каждый готовый трек
попадает в библиотеку сразу, не дожидаясь конца очереди.

### Плейлисты по ссылке

Вставь в поиск ссылку на **плейлист YouTube**, альбом или **сет SoundCloud** — приложение
прочитает его целиком (до 300 треков) и покажет списком, где уже отмечено всё, чего у тебя
ещё нет. Остаётся нажать «Скачать выбранное».

Ссылка вида `watch?v=...&list=...` считается ссылкой на один трек, а не на плейлист —
он просто заиграет.

### Ролики 18+

Такие YouTube отдаёт только тем, кто вошёл в аккаунт, и скачивание падает с ошибкой
«просит подтвердить возраст». Лечится в *Настройках → Стриминг → Куки браузера для YouTube*:
выбираешь свой браузер, и yt-dlp берёт оттуда куки, чтобы показать ютубу, что ты залогинен.

Куки читаются на твоём компьютере и уходят только на сам YouTube. По умолчанию выключено.
Браузер на время скачивания лучше закрыть — иначе он держит свою базу занятой.

## Обновления

*Настройки → Обновления*. При запуске приложение спрашивает у GitHub, не вышла ли версия
свежее. В сеть при этом уходит только номер твоей версии — больше ничего.

Найдя новую, оно **ничего не делает само**: показывает, что вышла, и ждёт. Нажмёшь
«Скачать» — скачает, нажмёшь «Перезапустить» — поставит и перезапустится. Проверку можно
выключить галочкой, тогда обновляться только вручную со страницы релизов.

Работает начиная с той версии, в которой появился сам обновлятор: сборка без него
о новых версиях узнать не может по определению.

## Перенос и бэкап

*Настройки → Перенос и бэкап*. **Сохранить бэкап** складывает в один json всю библиотеку,
плейлисты, избранное и настройки. **Восстановить из файла** возвращает всё обратно.

Это замена аккаунтам: файл можно унести на другой компьютер, положить в облако или просто
держать на случай, если что-то сломается.

Внутри — пути к файлам и теги, самой музыки там нет. Плейлисты и избранное хранятся
**путями**, а не внутренними id, поэтому переживают переезд на другую машину. Ключ YouTube
и Application ID в бэкап не пишутся. Треки, файлов которых на новом месте нет, просто
пропускаются — остальное встаёт по местам. После восстановления окно перезагружается,
чтобы подхватить приехавшие настройки.

## Студия: карточка и клип

Кнопка с фотоаппаратом в углу вкладки «Сейчас играет».

Кадр **собирается заново на своём холсте**, а не снимается с экрана: ни рамки окна, ни
боковой панели, ни очереди. Берётся обложка, цвет из неё, кольцо спектра вокруг обложки,
название с артистом и три строки текста — предыдущая, текущая с той же караоке-заливкой,
что и в плеере, и следующая. Внизу полоска времени.

Три формата: **сторис** 1080×1920, **квадрат** 1080×1080, **широкий** 1920×1080.

**Сохранить картинку** — png прямо сейчас, одним кадром.

**Записать клип** — 15, 30 или 60 секунд видео со звуком, начиная с текущего места трека.
Пишется в **mp4** (H.264 + AAC), если движок умеет, иначе в webm. Запись идёт в реальном
времени: тридцать секунд клипа — тридцать секунд ожидания. Кнопка во время записи
превращается в «Остановить», так что можно оборвать раньше.

Клип пишется только со **своих файлов**: у YouTube и SoundCloud звук играет внутри их
плеера, и снять его оттуда нельзя — для них доступна только картинка.

## Стриминг

Плеер проигрывает треки **целиком с серверов YouTube и SoundCloud** через их официальные
встроенные плееры. Ничего не скачивается, никаких токенов и обходов — эти плееры для того
и сделаны, чтобы чужие приложения могли проигрывать музыку у себя.

**Вставь ссылку** на трек с YouTube или SoundCloud в строку поиска — он сразу заиграет.
Перемотка, громкость, следующий-предыдущий и текст песни работают как со своими файлами.

**Поиск по YouTube** прямо в приложении требует бесплатный ключ Google:
[console.cloud.google.com](https://console.cloud.google.com/apis/library/youtube.googleapis.com)
→ включить **YouTube Data API v3** → **Создать учётные данные** → **Ключ API**.
Карта не нужна. Ключ вставляется в *Настройки → Стриминг* и хранится только на твоём компьютере,
в окно приложения он не попадает — запросы уходят из главного процесса.

Режим поиска переключается вкладками **Каталог** / **YouTube** над списком.

Два ограничения, честно:

**Эквалайзер и визуализация на таких треках не работают.** Звук идёт внутри чужого плеера,
мы его не слышим и спектр снять не можем. Текст песни при этом подхватывается — позицию
плеер нам сообщает. На своих файлах всё работает как раньше.

**YouTube показывает картинку** — маленькое окошко в углу. Прятать видео их правила
не разрешают. У SoundCloud только звук и волна.

### Чего тут нет

Встроенного доступа к **VK** и **Яндекс Музыке**. У VK музыка убрана из публичного API,
у Яндекса публичного API для сторонних приложений нет вообще. Всё, что «работает», —
это подделка официального клиента с чужим токеном: нарушает правила сервисов и ведёт
к блокировке аккаунта, чей токен используется. Поэтому для них — только поиск и переход
в сервис, а слушать целиком можно с YouTube и SoundCloud.

**Обложки.** Берутся из самого файла. Если их там нет — ищется `cover.jpg` рядом с треком,
а потом уже картинка в интернете по артисту и названию (Deezer, затем iTunes).
Отключается в настройках. В сеть уходит только текстовый запрос, сами треки никуда не отправляются.

**Цвет интерфейса** подстраивается под обложку играющего трека: полоска перемотки,
визуализация, подсветка — всё перекрашивается. В «Темах» можно вместо этого выбрать
свой постоянный цвет из палитры — он будет главнее обложки.

**Эквалайзер** на 10 полос, от 32 Гц до 16 кГц, ±12 дБ. Пресеты: плоский, бас, вокал,
яркий, клуб, ночь. Полосы тянутся мышкой или колесом, двойной клик обнуляет полосу.
Работает на честных фильтрах Web Audio, а не на подкрутке громкости.

**Таймер сна** — 15/30/45/60 минут или «в конце трека». Последние полминуты громкость
плавно уходит в ноль, чтобы не обрывало на полуслове. Пока таймер идёт, в панели тикает
обратный отсчёт: нажми на него, чтобы отменить.

**Скорость воспроизведения** — кнопка `1×` в правом нижнем углу. От 0.5× до 2×,
пресетами или ползунком. Переключатель «менять тон» отвечает за разницу между
честным ускорением и эффектом slowed, когда вместе со скоростью едет и высота голоса.
Перекодирования нет, всё считается на лету.

**Текст песни** тянется с lrclib.net и подсвечивается по времени. Если текст спешит или
опаздывает — в настройках есть сдвиг в секундах. Свой файл `.lrc`, положенный рядом с
треком с тем же именем, всегда главнее интернета.

Пять режимов подачи, переключаются в настройках:

| Режим | Как выглядит |
|---|---|
| **Караоке** | Текущая строка заливается цветом обложки по мере пения. Стоит по умолчанию |
| **Мягко** | Строки плавно проезжают к середине, соседние гаснут и размываются |
| **Фокус** | Только текущая строка, крупно, остальное почти не видно |
| **Лента** | Весь текст сразу, с мягким затуханием к краям |
| **Машинка** | Строка печатается по буквам в такт |

Отдельно настраиваются размер текста, свечение текущей строки и размытие соседних.

Строку текста можно **ткнуть мышкой** — трек перемотается на этот момент.
Клавиша **F** разворачивает текст на весь экран: панели уезжают, остаётся обложка и строки.
Возврат — `Esc`. Панели ненадолго возвращаются, если поводить мышкой.

## Темы

Отдельная вкладка. Сверху десять готовых тем — **Винил**, **Неон**, **Клуб**,
**Осциллограф**, **Пыль**, **Туннель**, **Лаборатория**, **Цветок**, **Отражение**,
**Чисто**. Каждая разом переключает визуализацию, форму обложки, фон и подачу текста.
Дальше всё то же можно крутить по отдельности, и тогда тема помечается как своя.

**Раскладка** — как расставлены обложка и текст. Переключается кнопкой в углу вкладки
«Сейчас играет» или клавишей **L**, пять вариантов:

| Вид | Что показывает |
|---|---|
| **Обложка сверху** | Как было: пластинка по центру, текст под ней |
| **Обложка слева** | Две колонки: обложка с подписью слева, текст во всю высоту справа |
| **Текст слева** | То же зеркально |
| **Только текст** | Обложки нет, строки крупнее, визуализация уходит в центр экрана |
| **Только обложка** | Текст спрятан, пластинка во весь рост |

**Визуализация** — считается с реального звука, двенадцать видов:

| Вид | Что рисует |
|---|---|
| **Кольцо** | Палочки спектра вокруг обложки |
| **Круговая волна** | Замкнутая осциллограмма с эхом вокруг обложки |
| **Осциллограф** | Живая волна по низу экрана с отражением |
| **Столбики** | Спектр столбиками во всю ширину снизу |
| **Пыль** | Частицы вокруг обложки, которые расталкивает басом |
| **Туннель** | Кольца улетают от обложки на каждую долю; чем дальше, тем быстрее |
| **Водопад** | Спектрограмма: свежий звук снизу, старый уползает вверх и тает |
| **Зеркало** | Столбики расходятся от средней линии вверх и вниз, низы в центре |
| **Спираль** | Точки по спирали: у центра низы, к краю верхи, каждая дышит своей полосой |
| **Лепестки** | Цветок из шести лепестков, каждый дышит своей полосой спектра |
| **Варп** | Звёзды летят на тебя, скорость держит бас |
| **Горизонт** | Сетка уходит за горизонт, на горизонте спектр далёким городом |

**Шрифты** — восемь штук, отдельно для интерфейса и отдельно для названия с текстом песни.
Плитка каждого шрифта написана им же, так что видно, что берёшь.

| Шрифт | Характер |
|---|---|
| **Системный** | Segoe UI, как в самой Windows |
| **Inter** | Чистый гротеск, ничего лишнего |
| **Manrope** | Мягкий геометрический |
| **Golos** | Русский гротеск, хорошо держит кириллицу |
| **Unbounded** | Дисплейный, широкий, заметный |
| **Oswald** | Узкий конденсед, хорош крупно |
| **Playfair** | Антиква с засечками |
| **JetBrains** | Моноширинный |

Файлы шрифтов лежат внутри приложения (латиница и кириллица), интернет для них не нужен.

**Обложка** — винил (крутится), квадрат или без рамки. Отдельно включается пульсация
в такт басу.

**Фон** — размытая обложка, видео из папки, картинка или ролик **по ссылке**, или просто
тёмный.

Для видео из папки: кидаешь туда любые mp4 или webm, плеер перемешивает их и крутит
по кругу, плавно переключая.

Для ссылки — вставляешь прямой адрес картинки (jpg, png, webp, gif) или видео (mp4, webm);
ролик зацикливается сам. Ссылка на *страницу* с картинкой не подойдёт: нужна та, что
открывается и показывает саму картинку. Обязательно **https** — обычный http политика
безопасности окна не пропустит. Под полем сразу пишется, что получилось: размер найденной
картинки или что по ссылке ничего нет.

Размытие и затемнение ползунками действуют на любой из этих фонов — раньше они меняли
только видео, обложку не трогали.

**В системе.** Отдельная вкладка показывает, что играет в других приложениях, с обложкой
и полоской времени. Кнопками оттуда можно переключать треки в чужом плеере.

**Горячие клавиши** работают, когда окно свёрнуто. По умолчанию:

| Действие | Клавиши |
|---|---|
| Пауза / играть | `Ctrl+Alt+Space` |
| Следующий трек | `Ctrl+Alt+→` |
| Предыдущий | `Ctrl+Alt+←` |
| Громче / тише | `Ctrl+Alt+↑` / `Ctrl+Alt+↓` |

Переназначаются в настройках: нажми на сочетание и набери новое.
Медиа-клавиши на клавиатуре и наушниках тоже работают. Если в нашем плеере ничего
не заряжено, нажатие уходит дальше — в Spotify или браузер.

Когда окно открыто, работают ещё `Пробел` (пауза), `←`/`→` (перемотка на 5 секунд),
`↑`/`↓` (громкость), `F` (текст на весь экран), `Esc` (выйти оттуда), `Ctrl+F` (поиск).

## Статус в Discord

Чтобы друзья видели, что ты слушаешь, нужен свой Application ID — без него Discord
не пустит. Делается один раз:

1. Зайти на https://discord.com/developers/applications
2. **New Application** → назвать. **Это название и увидят друзья** после слова «Слушает»,
   так что стоит написать что-то вроде `Вслух`.
3. На вкладке **General Information** скопировать **Application ID**.
4. Вставить его в настройках приложения и включить тумблер.

Если хочешь, чтобы в статусе показывалось и то, что играет в Spotify или браузере —
оставь включённым «Показывать и то, что играет в других плеерах».

Обложку Discord берёт из интернета по названию трека: у него нет доступа к файлам на диске.

## Как всё устроено

```
main.js              главный процесс: окно, горячие клавиши, локальный сервер
preload.js           мост между окном и системой
lib/
  store.js           настройки (%APPDATA%\vsluh\settings.json)
  library.js         сканирование папок, чтение тегов, кэш обложек
  artwork.js         поиск обложек в интернете
  lyrics.js          текст песни с lrclib.net + кэш
  search.js          поиск по каталогам Deezer и iTunes
  ytdlp.js           поиск, плейлисты и скачивание через yt-dlp
  dlqueue.js         очередь скачивания: по одному, с паузой и отменой
  backup.js          выгрузка и восстановление библиотеки одним файлом
  serve.js           локальный http-сервер для интерфейса и файлов
  smtc.js            связь с процессом слежки за чужими плеерами
  smtc-worker.js     сам мониторинг (отдельный процесс, см. ниже)
  mediakeys.js       отправка медиа-клавиш в Windows
  rpc.js             статус в Discord
src/                 само окно: index.html, style.css, app.js
```

Настройки, обложки и кэш текстов лежат в `%APPDATA%\vsluh`.
Удаление этой папки полностью сбрасывает приложение.

### Две неочевидные вещи

**Почему слежка за плеерами живёт в отдельном процессе.** Инициализация WinRT-монитора
внутри главного процесса Electron намертво вешает цикл событий — окно просто никогда не
появляется. Поэтому native-модуль запускается через `utilityProcess`, а наружу отдаёт уже
готовые снимки. Заодно его падение не утащит за собой всё приложение.

**Почему интерфейс грузится с локального `http://127.0.0.1`, а не из файла.** Сначала было
`file://` — но тогда браузерный движок считает обложки чужими: из них нельзя вытащить цвет
для интерфейса, и Windows отказывается показывать их в панели громкости. Свой протокол
`aung://` это чинил, но встроенный плеер YouTube отказывается работать с нестандартного
протокола — отдаёт «Ошибка 153». Обычный локальный адрес решает всё сразу.

Сервер слушает только петлю `127.0.0.1`, порт выдаётся системой при запуске, и файлы
пользователя отдаются только с секретом сессии — иначе любая страница в браузере могла бы
читать музыку с диска через наш же сервер. Сам интерфейс (html и css) отдаётся без секрета,
в нём ничего приватного нет.

## Чего тут нет и почему

**Стриминга из Spotify и Яндекс Музыки.** Их звук защищён DRM, стороннее приложение
проигрывать его не может — это ограничение самих сервисов, а не недоработка.
Поэтому сделано так: свою музыку плеер играет сам, а чужую — показывает и переключает
через системные медиа-клавиши.

**Скробблинга в Last.fm.** Не сделан, но добавляется несложно — скажи, если нужен.
