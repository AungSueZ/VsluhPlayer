# Шрифты

Шрифты в этой папке — не мои. Они встроены в приложение, чтобы интерфейс выглядел
одинаково без интернета. Каждый распространяется по своей лицензии, и её условия
действуют и здесь.

| Семейство | Лицензия | Откуда взят |
|---|---|---|
| Inter | SIL Open Font License 1.1 | https://github.com/rsms/inter |
| Manrope | SIL Open Font License 1.1 | https://github.com/sharanda/manrope |
| Golos Text | SIL Open Font License 1.1 | https://fonts.google.com/specimen/Golos+Text |
| Unbounded | SIL Open Font License 1.1 | https://fonts.google.com/specimen/Unbounded |
| Oswald | SIL Open Font License 1.1 | https://github.com/googlefonts/OswaldFont |
| Playfair Display | SIL Open Font License 1.1 | https://github.com/clauseggers/Playfair-Display |
| JetBrains Mono | Apache License 2.0 | https://github.com/JetBrains/JetBrainsMono |

Файлы `.woff2` собраны из официальных сборок и порезаны на подмножества по алфавитам
(латиница, кириллица, расширенная кириллица) — сами очертания букв не менялись.

Текст SIL Open Font License 1.1: https://openfontlicense.org
Текст Apache License 2.0: https://www.apache.org/licenses/LICENSE-2.0

Полное соблюдение OFL требует, чтобы рядом лежал и сам текст лицензии с копирайтом
автора — файл `OFL.txt` из репозитория каждого шрифта. Если планируешь распространять
сборку широко, положи их сюда же.
